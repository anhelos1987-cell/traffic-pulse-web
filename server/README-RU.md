# VK Games: «Открыть все карты» — 10 голосов

Подготовлена интеграция для приложения **54870403**. Идентификатор товара —
`unlock_all_maps`, цена на сервере — **10 голосов**, разовая покупка.
Открываются карты кампании и выбор её уровней, включая последующие циклы.
Покупка не выдаёт звёзды, монеты, машины и отметки о прохождении.
Ежедневные заезды, сценарии и задания «Зелёная волна» сохраняют свои правила
открытия: они не являются покупаемыми картами кампании.

## Текущий статус

Клиент и платёжный обработчик реализованы и проверены автоматическими тестами.
В `payments-config.js` стоит `enabled:false`: реальные списания не включены,
предложение покупки скрыто. Секрет VK Games и callback для этого приложения
не настроены. Старый VK Play billing и его секрет не используются.

## Размещение сервера

Разместить `vk-payments.mjs` на сервере в РФ с Node.js **24 LTS** и постоянным
локальным диском. SQLite сохраняет минимальный журнал заказов: ID заказа,
VK ID получателя, товар, цена, статус, признак теста, время изменения.
В Cloudflare эти данные не передаются и не сохраняются. Сам платёжный сервер
не следует размещать за Cloudflare Proxy. Настроить HTTPS на российском хосте.
У прокси не журналировать POST-тела, заголовки авторизации и launch-параметры.

Скопировать `.env.example` в приватный файл окружения сервера и заполнить:

- `VK_APP_SECRET`: защищённый ключ приложения **54870403**, только на сервере;
- `VK_PAYMENTS_DB`: путь постоянной базы, каталог должен существовать;
- `VK_PAYMENTS_LIVE=false`: сначала только тесты;
- `VK_TEST_USERS`: VK ID тестировщиков через запятую;
- `VK_ALLOWED_ORIGINS`: точный origin страницы игры;
- `VK_ITEM_PHOTO_URL`: публичный HTTPS-адрес иконки товара;
- `HOST`, `PORT`: адрес за HTTPS-прокси, по умолчанию `127.0.0.1:8080`.

Запуск: `node --env-file=/private/path/payments.env server/vk-payments.mjs`.
Базу и резервные копии хранить в РФ. Один экземпляр приложения работает
с одной локальной базой; не использовать эфемерный диск контейнера.
Секрет и базу не коммитить и не добавлять в клиентский архив.

## Настройка VK

В разделе «Платежи» приложения **54870403** указать адрес обратного вызова:
`https://<российский-домен>/api/vkgames/callback`.
Обработчик отвечает на `get_item`, `order_status_change` и их тестовые версии.
Каталог и цена возвращаются сервером, а не принимаются от клиента.
В кабинете включить тестовый режим и добавить тестировщиков. Перед включением
боевой оплаты нужно проверить актуальные требования кабинета и один настоящий
тестовый цикл callback: тесты с подставленными уведомлениями не заменяют его.

## Подключение клиента после готовности сервера

В `payments-config.js` задать `enabled:true`, `endpoint` — HTTPS origin сервера
в РФ. Сохранить `appId:54870403`, `item:'unlock_all_maps'`, `priceVotes:10`.
В CSP страницы `index.html` и `infra/cloudflare-vkgames-worker.js` заменить
`connect-src 'none'` точным origin этого сервера. Остальные источники не добавлять.
Обновить версии скриптов в HTML и `CACHE_VERSION` Worker, затем опубликовать.

Кнопка находится в карте кампании. Проверка покупки запрашивается только при
открытии карты, восстановлении и оплате, без нового запроса при старте игры.
Платёжный диалог вызывается через VK Bridge, а доступ выдаётся исключительно
после проверки подписанных серверных уведомлений VK. Локальные флаги,
`order_id` или сообщение об успехе от клиента сами по себе не открывают карты.

## Обязательный тест перед боевым включением

1. Приложение VK открывает товар и показывает **10 голосов**.
2. Отмена не открывает карты. Двойное нажатие открывает один диалог.
3. Успешный тестовый callback создаёт один заказ и открывает карты.
4. Повторное уведомление возвращает тот же ответ без второй выдачи.
5. Покупка восстанавливается после перезапуска, на другом устройстве и после
   удаления игрового прогресса; другой аккаунт её не получает.
6. Возврат оплаты убирает платный доступ при следующей проверке покупки.
7. Переход на уровень 117 не отмечает 1–116 пройденными, не открывает машины
   и не начисляет чужие награды. Звёзды позднего уровня сохраняются.
8. При недоступном сервере новое списание не инициируется. После перезапуска
   до восстановления связи остаются доступны уровни, открытые прохождением.
9. После одобрения платёжных настроек включить `VK_PAYMENTS_LIVE=true`.
   Тестовые заказы не становятся боевыми покупками.
