# Traffic Pulse 🚦

**Traffic Pulse** — браузерная HTML5-игра об управлении дорожным движением. Машины автоматически едут по перекрёсткам, а игрок переключает светофоры, чтобы пропустить поток без столкновений и критических пробок.

Игра рассчитана на смартфоны и ПК. Управление: нажатие/тап по светофору или игровому полю, `Space` на ПК; в режиме «Зелёная волна» используются отдельные светофоры (`1` и `2`). Интерфейс поддерживает русский и английский языки.

> **Важно:** этот репозиторий содержит **разные платформенные ветки**, а не одну универсальную сборку. Изменения из одной ветки не переносятся в другую автоматически.

## Ветки и платформы

| Ветка | Назначение | Статус |
| --- | --- | --- |
| `main` | **VK Play**, браузерный/iframe-снимок M197 | Отдельная историческая сборка, не основная ветка VK Games |
| `vk-games` | **VK Games / VK Mini Apps и OK Games**, VK Bridge, облачное хранилище и нативная реклама | Основная проверенная ветка M201, до объединения новых PR |
| `release/yandex` | **Яндекс Игры**, интеграция через `/sdk.js` | Независимая платформенная ветка |
| `feature/m202-…` → `feature/m212-…` | Последовательные доработки над `vk-games` (сохранения, симуляция, UX, производительность, обучение, архитектура, целостность релиза и синхронизация) | **Черновики**: не опубликованы и не объединены с `vk-games` |

Версии в названиях файлов и веток — внутренние номера этапов разработки, а не подтверждение публикации в магазинах.

## Быстрый локальный запуск

Проект — статический HTML/CSS/JavaScript, сборщик и `npm install` для самого клиентского приложения не требуются.

```bash
git clone https://github.com/anhelos1987-cell/traffic-pulse-web.git
cd traffic-pulse-web
git checkout vk-games
python3 -m http.server 8000
```

Откройте `http://localhost:8000/` в браузере. Для других платформ переключитесь на соответствующую ветку **до** запуска локального сервера.

**Ограничение:** локальный сервер не заменяет окружение VK/OK/Yandex: авторизация, реклама, платежи и облачные сохранения должны отдельно проверяться в платформенном тестовом контейнере. `/sdk.js` у Яндекс Игр предоставляется платформой.

## Проверки VK Games / OK Games

На ветке `vk-games` и производных feature-ветках используются Node.js **22** и Python **3**.

```bash
node --check app.js
node --check vk-games.js
node --test tests/*.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

CI GitHub Actions расположен в `.github/workflows/vk-games-ci.yml`. В ветках M205+ дополнительно доступен информационный микробенчмарк:

```bash
node scripts/benchmark-m205-hotpaths.mjs
```

Микробенчмарк не гарантирует прирост FPS на мобильном устройстве. Перед публикацией обязательны реальные проверки на Android/iOS, включая паузу/возобновление, рекламу, облако, 30-минутную сессию и разные размеры экрана.

## Организация кода

Состав зависит от выбранной платформенной ветки.

| Файл | Роль |
| --- | --- |
| `index.html`, `style.css` | Разметка, адаптивный интерфейс, стили |
| `app.js` | Игровая симуляция, Canvas-отрисовка, игровой цикл и основной UI |
| `progress-core.js` | Нормализация и объединение прогресса |
| `campaign-access.js` | Доступ к уровням отдельно от заработанного прогресса (VK Games) |
| `vk-games.js` | VK/OK Bridge, облачные сохранения, платформенная реклама (VK Games) |
| `vk-purchases.js`, `payments-config.js`, `server/` | Платформенные покупки, конфигурация и серверная верификация (VK Games) |
| `player-guidance-core.js` | Чистые правила подсказок и индикации, выделенные в **черновой M207** |
| `tests/` | Node/Python регрессионные проверки (VK Games) |

Новые модули подключаются в `index.html` перед `app.js`. Не переносите SDK-файлы, настройки платежей и CSP между платформенными ветками без отдельной проверки.

## Безопасная разработка и выпуск

1. Изменения делаются в отдельной feature-ветке, а не напрямую в опубликованной платформенной ветке.
2. Автотесты и статические проверки GitHub Actions должны пройти.
3. Проверяются реальные VK/OK/Yandex callback-и, офлайн/онлайн-восстановление и сохранение прогресса.
4. PR проходит ревью и только после этого объединяется в целевую платформенную ветку.
5. Публикация на игровой платформе — отдельное действие; успешный CI сам по себе **не означает выпуск**.

Ветки M202–M207 наследуются последовательно. Их нельзя выборочно объединять без учёта зависимостей и повторной проверки. Приватная копия репозитория в Яндекс SourceCraft не синхронизируется с GitHub автоматически.

Для ветки M208+ CI также запускает реальный Chromium smoke через скрипт `scripts/browser-smoke-vkgames.mjs`: он требует `puppeteer-core` и Chrome/Chromium (в CI устанавливается только зависимость теста). Это локальный запуск без реальных SDK-callbacks.

В M209 есть проверка конкурентных облачных записей. **VK Storage не поддерживает атомарный compare-and-swap:** полное отсутствие потери данных при одновременной записи с разных устройств пока не гарантируется. Подробности — в `docs/M208_M209_QA.md`.

**Секреты, токены и платёжные ключи не должны находиться в клиентском коде или коммититься в Git.**
